Sport - Eventi per Kodi

Repository per Kodi 19 o successivo.

  • repository.sporteventi-1.0.0.zip

In Kodi: Gestore file → Aggiungi sorgente → https://bonalapizza9.github.io/sport-eventi-kodi/

Poi Add-on → Installa da un file ZIP → scegli questa sorgente e il repository. Infine Installa da repository → Sport - Eventi Repository → Add-on video → Sport - Eventi.

Gli ZIP sono pubblici. Le fonti video possono non essere disponibili.
